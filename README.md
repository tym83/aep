# Aenix Enterprise Platform (AEP)

AEP turns [Cozystack](https://cozystack.io) into a ready-to-use internal platform for large organisations. Cozystack provides the infrastructure — tenants, managed databases and queues, tenant Kubernetes clusters, virtual machines, backups, GPUs. [OpenChoreo](https://openchoreo.dev) provides the application layer — projects, components, environments, release promotion and a Backstage-based developer portal. AEP connects the two and adds what enterprises require on top: organisations with isolated environments, managed services for applications, change management with segregation of duties, ITSM integration, policy reports, audit export, cost allocation and AI-assisted incident analysis on the customer's own hardware.
